==============================================================================
FraudGraph AI — Baseline vs GraphSAGE Model Comparison (single seed)
==============================================================================

Dataset       : 677930 transactions (466 users, 14868 merchants)
Split (temporal, earliest -> latest):
  train : 338965
  val   : 67793
  test  : 271172  (354 fraud, base rate 0.1305%)

Features (identical across every model, incl. GraphSAGE's node features):
  amount (log1p, standardized), hour-of-day (sin/cos), day-of-week (sin/cos),
  channel one-hot [Swipe/Chip/Online], has_error flag
  -> GraphSAGE additionally sees the card<->transaction<->merchant graph structure.

NOTE: this is a single seeded run. See robustness_results.txt for a
multi-seed sweep — single-run rankings between close models are not reliable
(see that file's notes on GraphSAGE vs XGBoost variance).

------------------------------------------------------------------------------
Notes
------------------------------------------------------------------------------
- PR-AUC (average precision) is the primary metric given the heavy class
  imbalance in this dataset; ROC-AUC is included for reference.
- Rule-based = handcrafted anomaly score (anomaly.py), no training.
- Classical baselines and GraphSAGE are trained on the SAME temporal split
  and SAME flat feature matrix (gnn.txn_features); GraphSAGE additionally
  sees the card/merchant graph topology.
