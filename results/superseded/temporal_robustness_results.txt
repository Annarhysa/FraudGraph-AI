Part B/C: Temporal Robustness — GraphSAGE vs Tuned XGBoost across evaluation windows
============================================================================================

Frozen configs (no re-tuning in this experiment):
  XGBoost:   max_depth=5, learning_rate=0.05, n_estimators=300, seed=42
  GraphSAGE: hidden_dim=32, epochs=100, lr=0.01, seeds=[0, 1, 2]

NOTE: 3 seeds (not the original 5) are used per window here to keep this
multi-window sweep's CPU-only runtime bounded (this is 3x the model-training
volume of the single-window 5-seed sweep). Mean+/-std is still reported, but
treat the per-window std as a slightly less precise estimate than Window 0's.

Window 0 (reference, NOT re-run here) = the ORIGINAL default 50/10/40 split
used in every earlier experiment. Its test period runs Sep 2019 -> Feb 2020,
i.e. ~71% of its test rows fall in the zero-fraud Nov-Feb tail (see Part A).
Windows 1-3 below keep test entirely inside the fraud-bearing Jan-Oct region.
